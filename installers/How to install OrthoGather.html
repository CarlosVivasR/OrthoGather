How to install OrthoGather

No commands, no setup knowledge needed. Download one file, double-click, and you're done. Pick your computer below.

Install OrthoGather.commandWorks on all Macs (Apple Silicon & Intel)
Download
1

Download the installer

Click the Download button above and save Install OrthoGather.command (it usually lands in your Downloads folder).

2

Open it (the first time, right-click → Open)

Find the file, right-click it (or Control-click) and choose Open. A box says it's from an unidentified developer — click Open again.

This security step only happens the first time. It's normal for free tools that aren't from the App Store.
3

Let it run

A black Terminal window opens and shows progress. It installs everything it needs and downloads the scientific tools. Leave it open — the first time takes a few minutes.

The first install downloads ~1–2 GB. A progress bar that looks stuck is usually still working — give it time.
4

You're done 🎉

When it finishes you'll have an OrthoGather app (with the logo) on your Desktop and in Launchpad / Applications.

5

To use it — now and every time after

Just double-click OrthoGather (the app with the logo). It opens automatically in your web browser. That's the whole app.

Install OrthoGather.batWindows 10 (2020+) or Windows 11
Download
Why Windows is a little different: the science engine (OrthoFinder) only runs on Linux, so the installer quietly sets up a small Linux inside Windows (called WSL). You don't have to do anything — it handles it, but it needs one restart.
1

Download the installer

Click Download above and save Install OrthoGather.bat.

2

Run it

Double-click the file. If a blue "Windows protected your PC" box appears, click More info → Run anyway. Then click Yes on the permission prompt.

That warning is normal for free tools. The permission (admin) is needed to set up the Linux part.
3

Restart when it asks

It installs WSL and then says it needs a restart. Save your work and restart your PC.

4

It continues by itself

After the restart the installer picks up automatically. If a Linux (Ubuntu) window asks you to create a username and password, type a simple one and remember it. Then it downloads everything (a few minutes).

5

You're done 🎉

You'll get an OrthoGather shortcut (with the logo) on your Desktop.

6

To use it — now and every time after

Double-click OrthoGather on your Desktop. A small window opens and, a few seconds later, the app appears in your web browser.

Good to know
You only install once. After that, you just double-click the OrthoGather icon whenever you want to use it.
A little window stays open while you work. That's the engine running. Keep it open while you use OrthoGather; close it to stop the app.
To update later, just run the installer again — it refreshes your install and keeps your data.
What you need

Free disk space

~3 GB on a Mac, ~5 GB on Windows (Windows is bigger because it also sets up a small Linux). The first install downloads about 1–2 GB.

Memory & system

8 GB RAM is comfortable for typical analyses. macOS (Apple Silicon or Intel) or Windows 10 (2020 or newer) / Windows 11. An internet connection for the first install.

If something looks off
macOS won't let me open the file
Don't double-click — instead right-click (or Control-click) the file and choose Open, then Open again in the box. If you still can't, go to System Settings → Privacy & Security, scroll down, and click Open Anyway.
Windows shows "Windows protected your PC"
Click More info, then Run anyway. This appears because the installer isn't code-signed yet; it's safe to run.
It seems frozen during the first install
The first install downloads large scientific packages. A progress bar that sits still for a minute or two is usually fine — please wait. Closing the window cancels it.
The browser didn't open
Open your web browser yourself and go to http://localhost:5000 (Windows) or the address shown in the window (Mac). Make sure the small OrthoGather window is still open.
