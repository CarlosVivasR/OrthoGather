How to install OrthoGather

No commands, no setup knowledge needed. Download one file, double-click, and you're done. Pick your computer below.

Install OrthoGather (Mac).zipWorks on all Macs (Apple Silicon & Intel)
Download
1

Download & unzip

Click the Download button above to save Install OrthoGather (Mac).zip (it usually lands in your Downloads folder). Then double-click the .zip to unzip it — you'll get a file called Install OrthoGather.command.

2

Open it — get past the security warning

Double-click Install OrthoGather.command. macOS shows a warning that it “could not verify it is free of malware”. That's only because the app isn't from the App Store — it's not a real problem. Get past it like this:

The reliable way (works on every Mac): click whatever button closes the warning (it may say Done, OK or Cancel — none of them block the app), then open System Settings → Privacy & Security, scroll down to the line mentioning Install OrthoGather.command, and click Open Anyway (confirm once more if asked).
On older Macs you can instead right-click (or Control-click) the file → Open → Open. Newer macOS versions may not offer this, so use the method above if you don't see it.
This security step only happens once. It's normal for free tools that aren't from the App Store.
3

Let it run — don't touch anything

A black Terminal window opens and fills with text as it downloads the scientific tools. The first install moves ~1–2 GB and takes about 5–15 minutes. You'll see lots of packages scroll past.

It will look frozen at times — that's completely normal, it is NOT stuck. Do not close it or touch anything until you see one of two things: an error message, or the words “OrthoGather installed!”. Then you're done.
4

You're done 🎉

When it finishes you'll have an OrthoGather app (with the logo) on your Desktop and in Launchpad / Applications.

5

To use it — now and every time after

Just double-click OrthoGather (the app with the logo). It opens automatically in your web browser. That's the whole app.

Install OrthoGather (Windows).zipWindows 10 (2020+) or Windows 11
Download
Why Windows is a little different: the science engine (OrthoFinder) only runs on Linux, so the installer quietly sets up a small Linux inside Windows (called WSL). It handles almost everything for you — it just needs one restart partway through, then reopens and continues on its own. No commands, no Linux username to create.
1

Download & unzip

Click Download above to save Install OrthoGather (Windows).zip. Then right-click the .zip → Extract All to unzip it into a real folder, open that folder, and you'll find Install OrthoGather.bat.

Do extract it first — don't run the installer straight from inside the zip preview window, or it can fail. Use Extract All, then open the extracted folder.
2

Run it

Double-click the file. If a blue "Windows protected your PC" box appears, click More info → Run anyway. Then click Yes on the permission prompt.

That warning is normal for free tools. The permission (admin) is needed to set up the Linux part.
3

Restart if it asks

If the Linux components need turning on, the installer asks to restart — press Y and it restarts for you (save your work first). After the restart it should reopen and continue by itself.

If it doesn't reopen on its own a minute or two after you log back in, no problem — just open the extracted folder and run Install OrthoGather.bat again (double-click it). It picks up exactly where it left off.
4

It sets up Linux by itself

The installer turns on the Windows Linux components, installs Ubuntu, and downloads everything it needs — all automatically. There's no username or password to create, and it shows you what it's doing at each step.

The download is ~1–2 GB and takes about 5–15 minutes. It will look frozen at times — that's completely normal, it is NOT stuck. Leave the window open until you see an error message or the words “OrthoGather is installed!”.
If a window ever closes unexpectedly, don't worry — just run the installer again. It saves its progress and resumes where it left off.
5

You're done 🎉

You'll get an OrthoGather shortcut (with the logo) on your Desktop.

6

To use it — now and every time after

Double-click OrthoGather on your Desktop. A small window opens and, a few seconds later, the app appears in your web browser.

Good to know
You only install once. After that, you just double-click the OrthoGather icon whenever you want to use it.
A little window stays open while you work. That's the engine running. Keep it open while you use OrthoGather; close it to stop the app.
To update later, just run the installer again — it refreshes your install and keeps your data.
What you need

Free disk space

~3 GB on a Mac, ~5 GB on Windows (Windows is bigger because it also sets up a small Linux). The first install downloads about 1–2 GB.

Memory & system

8 GB RAM is comfortable for typical analyses. macOS (Apple Silicon or Intel) or Windows 10 (2020 or newer) / Windows 11. An internet connection for the first install.

If something looks off
macOS won't let me open the file
Way 1 (easiest): go to System Settings → Privacy & Security, scroll down to the line about the file, and click Open Anyway.

Way 2 (older Macs): right-click (or Control-click) the file → Open → Open again.

Way 3 (last resort, Terminal): if both are blocked, open Terminal, paste the line below and press Return (adjust the path if the file isn't in Downloads):
xattr -dr com.apple.quarantine ~/Downloads/"Install OrthoGather.command" && chmod +x ~/Downloads/"Install OrthoGather.command"
Windows shows "Windows protected your PC"
Click More info, then Run anyway. This appears because the installer isn't code-signed yet; it's safe to run.
My antivirus blocked or deleted the download
Some managed or work computers (for example with Sophos) block downloading program files. That's why OrthoGather is given to you as a .zip, which is normally allowed. If the download is still blocked, or the file disappears after downloading, it's your organisation's security policy stopping it — ask your IT support to allow it, or contact Carlos for another way to get the file.
Windows: it says it can't start Linux / virtualization is off
The installer checks this for you and tells you if it's the problem. Linux inside Windows needs “virtualization” switched on in your computer's BIOS/UEFI — this is the one thing an installer can't turn on for you. Restart the PC, open the BIOS (usually by tapping F2, F10, DEL or ESC as it powers on), find a setting named Virtualization Technology, Intel VT-x, AMD-V or SVM, set it to Enabled, save and exit, then run the installer again. If you get stuck, send Carlos the log file the installer saves at %LOCALAPPDATA%\OrthoGather\install-log.txt.
It seems frozen during the first install
This is the most common worry — and almost always nothing is wrong. The first install downloads large scientific packages (~1–2 GB, 5–15 minutes) and goes quiet for a minute or two at a time. Keep waiting until you see either an error or “OrthoGather installed!”. Closing the window is the only thing that cancels it, so just leave it be.
The browser didn't open
Look at the small OrthoGather window — it prints the exact address to open (for example http://localhost:5000; it may be a different number if 5000 was busy). Type that address into your web browser. Make sure that window stays open.
