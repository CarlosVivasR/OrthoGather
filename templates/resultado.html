Figure 3: UpSet of shared orthogroups

Each bar is a unique combination of species. Hover or click bars for details.

How the highlight works

Hover a species row to see which combinations contain it. Bars that include the species are painted amber; the rest stay black.

In this figure each bar counts orthogroups. Every orthogroup in a combination belongs to all the species in that combination by definition, so the highlight is binary: 100 % when the combination contains the hovered species, 0 % otherwise.

Hovering a bar highlights the matrix dots of the species that compose it.

Figure 4: UpSet of shared proteins

Same intersections as Figure 3 but weighted by total proteins, not orthogroup count.

How the highlight works

Hover a species row to see how many proteins each combination borrows from it. The amber portion of each bar is proportional to that species' protein contribution to the intersection.

If the combination contains 3 species, each contributes some proteins to the shared orthogroups; the highlight shows the actual share of the hovered species (not a flat 1/3).

Bars whose combination does not include the hovered species stay black (no amber).
