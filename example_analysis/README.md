# Worked example

This folder holds the worked example described in **Supplementary File S1** of the paper.
OrthoFinder was run on 5 August 2026, and every file was exported with OrthoGather v2.1.0 on
13–14 September 2026. Each file is the application's own export, with its original file name; only
the folder structure was added. Each result has its own folder with every format the application
offers for it.

## Source dataset

Giddey, A. D., de Kock, E., Nakedi, K. C. et al. (2017).
*A temporal proteome dynamics study reveals the molecular basis of induced
phenotypic resistance in Mycobacterium smegmatis at sub-lethal rifampicin
concentrations.* Scientific Reports 7:43858.
<https://doi.org/10.1038/srep43858>

Protein identifiers were taken from that paper's supplementary material and standardised to
UniProt accessions. Because proteins that increase and proteins that decrease in abundance describe
opposite biological responses, the 491 differentially abundant proteins were split by direction and
analysed as two independent foregrounds against a common background.

## Contents

### `input_dataset/`

| File | Contents |
|---|---|
| `foreground_down-regulated_306.txt` | 306 proteins less abundant after rifampicin |
| `foreground_up-regulated_185.txt` | 185 proteins more abundant after rifampicin |
| `background_3181.txt` | the 3,181 proteins detected in the study |
| `Example_dataset_Foreground_Background.xlsx` | the same lists as a workbook |

### `0_run_metadata/`

- `provenance/`: software and database versions of the run, in text and JSON. They were exported
  before the Gene Ontology step, so their GOA fields are empty; the GOA versions are recorded in
  the `Provenance` worksheet of each results workbook.
- `citation/`: BibTeX and RIS entries generated by the application. Like every citation export of
  v2.1.0, they carry an earlier title of the paper, and the BibTeX author list is not in BibTeX
  format; to cite OrthoGather, use the reference in the main [README](../README.md#citation).
- `taxonomy-tree/`: taxonomic dendrogram of the six species, in Newick format.

### `1_orthofinder/`

OrthoFinder output for the six species, as downloaded from the run summary: one zip containing
`Orthogroups.tsv`, `Orthogroups.GeneCount.tsv`, `Orthogroups_UnassignedGenes.tsv` and
`Orthogroups.txt`, which can be loaded again with **External Upload**. **5,949 orthogroups.**

### `2_comparative_analysis/`

One folder per figure, each with the image (PNG and SVG) and its data (XLSX, CSV, TSV, JSON). For
the UpSet figures (3–6), the XLSX workbook has one worksheet per intersection, listing its
orthogroups and UniProt accessions; the CSV, TSV and JSON files hold the plotted counts.

| Folder | Figure |
|---|---|
| `figure1_protein-distribution` | proteins per orthogroup |
| `figure2_orthogroup-sharing` | orthogroups by number of species |
| `figure3_upset-orthogroups` | UpSet, orthogroups, three species |
| `figure4_upset-proteins` | UpSet, proteins, three species |
| `figure5_upset-orthogroups-filtered` | the same, restricted to the 430 orthogroups that contain a foreground protein |
| `figure6_upset-proteins-filtered` | the same, for proteins |

### `3_go_annotation/`

- `annotation-coverage-per-orthogroup/`: GO annotation coverage per orthogroup (XLSX, and zipped
  CSV and TSV). Worksheets: Meta, Initial Groups, Filtered Groups, Removed Groups, Groups of
  Interest, Species & GOA Map and Provenance. **4,638 of the 5,949 orthogroups contain at least one
  annotated protein.**
- `annotation-coverage-histogram/`: the coverage histogram as exported.

### `4_go_enrichment/`

One folder per direction of change, each split into `chart/` (PNG, SVG), `results/` (XLSX, zipped
CSV and TSV) and `table/` (CSV, TSV, JSON).

| Folder | Result |
|---|---|
| `down-regulated_306/` | 306 submitted, 250 annotated, tested against the 2,470-protein annotated universe. **21 enriched terms** (20 BP, 1 MF). |
| `up-regulated_185/` | 185 submitted, 162 annotated. **1 enriched term**; the chart and the table also carry the two terms at FDR 0.059. |

Both runs used all evidence codes, per-protein counting, all orthogroups (not only single-copy
ones), no expansion to full orthogroups, a one-sided Fisher's exact test, minimum GO depth 2, term
sizes of 10–500 background proteins, and Benjamini–Hochberg correction applied once across the
three namespaces (613 terms in the correction family). The `Provenance` worksheet of each results
file records these settings except the expansion and single-copy settings, which it does not store.

## Reproducing this analysis

1. **Install OrthoGather** following the [installation guide](../docs/Installation_guide.pdf). The
   installers install the current version; to use exactly v2.1.0, clone it with
   `git clone --branch v2.1.0 https://github.com/CarlosVivasR/OrthoGather.git` and follow the Conda
   route.
2. **New Analysis.** Search for and select these six UniProt reference proteomes, then click
   **Download proteomes** and **Run OrthoFinder**:
   `UP000000757` (*M. smegmatis* mc²155), `UP000007137` (*M. abscessus* ATCC 19977),
   `UP000498640` (*A. baumannii* ATCC 19606), `UP000001035` (*B. cenocepacia* J2315),
   `UP000000625` (*E. coli* K-12) and `UP000002438` (*P. aeruginosa* PAO1).
3. **Protein Analysis (figures 1–6).** Figures 1 and 2 cover all six species. For figures 3 and 4,
   select *E. coli* K-12, *M. abscessus* and *M. smegmatis* and click **Generate UpSet figures**.
   For figures 5 and 6, paste the 491 identifiers of both foreground lists together into
   **Filter by UniProt IDs** and click **Generate filtered figures (5 & 6)**: 467 map to 430
   orthogroups and 24 are unassigned.
4. **Gene Ontology tab.** Check that the six species are matched in **Species match**, click
   **Download GOA files**, review the **Annotation overview** and click
   **Continue to GO enrichment**.
5. **Enrichment.** Paste `foreground_down-regulated_306.txt` as the foreground and click
   **Load foreground**. Paste `background_3181.txt` as the background, leaving
   **Use all GOA files** unticked, and click **Load background**. Leave **Expand to full
   orthogroups** unticked and keep the default settings, then click **Run GO enrichment**: the
   result is 21 enriched terms. Repeat with `foreground_up-regulated_185.txt`, which gives one
   term; to show the two terms at FDR 0.059 as in the exported chart, set **Show down to FDR** to
   0.06 or more (for example 0.1) and click **Re-run with new thresholds**.

To copy a list, open the file on GitHub and use the "Copy raw file" button, then paste it into the
application. The same files are on your computer, in the `example_analysis/input_dataset/` folder
of your OrthoGather installation.

GO annotation files are downloaded from the EBI GOA repository, which is updated monthly, and
UniProt releases also change over time, so a later run may differ slightly from these results. The
versions used were:

| | |
|---|---|
| OrthoGather | 2.1.0 |
| OrthoFinder | 2.5.5 |
| GOATOOLS | 1.6.4 |
| UniProt release | 2026_02 |
| Proteome catalogue | 2026-06-03 |
| Gene Ontology | releases/2026-07-26 |
| EBI GOA proteomes generated | 2026-07-28 |

As an example of that drift, re-running the analysis on 20 October 2026 (UniProt 2026_03, GOA files
generated on 2026-10-11) gave 5,952 orthogroups instead of 5,949, and 2,480 annotated background
proteins instead of 2,470. The 306 proteins decreased in abundance gave 23 enriched terms: the 21
reported here plus *acyltransferase activity* and *protein catabolic process*. The 185 increased in
abundance gave the same single term, and the 491 analysed together gave five terms instead of one.
OrthoFinder itself is deterministic: on the same proteomes it gives the same orthogroups. The files
in this folder reproduce the published numbers exactly, and OrthoGather 2.2.0 reproduces them from
these files.
