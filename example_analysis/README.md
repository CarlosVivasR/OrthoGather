# OrthoGather – Example Analysis (Manuscript Submission Version)

This directory contains the complete reproducible example analysis described in the manuscript:

**"OrthoGather: a local platform for orthology-based proteome and proteomics comparisons and Gene Ontology enrichment"**

## Contents

### 1. Input Dataset

`input_dataset/Example_dataset_Foreground_Background.xlsx`

- Foreground: 596 proteins differentially expressed in *Mycolicibacterium smegmatis*  
- Background: 3,244 proteins detected in the same study  
- Source: Giddey et al., Scientific Reports (2017)

This dataset was used to demonstrate the full OrthoGather workflow.

---

### 2. Output Files

`output_files/`

This folder contains the complete output generated by OrthoGather for the example analysis, including:

- OrthoFinder orthogroup tables  
- UpSet plot figures and associated data tables  
- GO annotation coverage analysis  
- GO enrichment results (Fisher’s exact test with Benjamini–Hochberg FDR correction)

These files correspond to Supplementary Data S4 described in the manuscript.

---

## Reproducibility

All outputs were generated using the default OrthoGather pipeline as described in the Methods section of the manuscript.  
The analysis can be reproduced by running OrthoGather locally and providing the example dataset as input.
