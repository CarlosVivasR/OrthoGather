Install OrthoGather

A local platform for orthology-based proteome comparison and Gene Ontology enrichment. Three steps and you're running it on your own machine — no cloud, no command-line expertise required.

Python 3.11 OrthoFinder 2.5.5 macOS · Linux · WSL No Rosetta
Easiest: one-click installer

No terminal, no commands. Download the installer for your computer, double-click it, and it sets up everything — including OrthoFinder — and puts an OrthoGather launcher on your Desktop.

macOS

Apple Silicon & Intel. Download Install OrthoGather.command and double-click it.

First time: right-click → Open to get past the macOS security prompt.

Windows 10/11

Download Install OrthoGather.bat and double-click it. It enables WSL (needs admin + one restart, then continues by itself).

If SmartScreen warns: More info → Run anyway.

The installer downloads ~1–2 GB the first time (OrthoFinder + scientific packages) — give it a few minutes. Re-running it later just updates your install.
Advanced: manual install

Prefer the command line, or already use conda? Here's the manual route.

Before you start

Conda or Micromamba

The package manager that builds the environment. Don't have it? Install Miniforge (free, lightweight).

Git

To download the code. The proteome catalogue ships compressed inside the repo — no Git LFS needed, it unpacks itself on first launch.

A terminal

macOS Terminal, a Linux shell, or Windows + WSL. Everything below is copy-paste.

~3 GB free space

For Python 3.11, OrthoFinder and the UniProt catalogue (~3 GB on macOS/Linux; ~5 GB on Windows because of WSL). 8 GB RAM recommended.

Install in 3 steps
1

Download OrthoGather

Clone the repository and move into the folder. A plain git clone is all you need — the proteome catalogue travels inside the repo, compressed.

git clone https://github.com/CarlosVivasR/OrthoGather.git
cd OrthoGather
2

Create the environment

This one command installs Python 3.11, OrthoFinder 2.5.5 and every dependency, then activates it.

conda env create -f environment.yml
conda activate orthogather
micromamba env create -f environment.yml
micromamba activate orthogather

The first build takes a few minutes — it downloads OrthoFinder and the scientific packages.

3

Launch it

Start the app — it picks a free port and opens your browser automatically.

python app.py

On the first launch the app unpacks the proteome catalogue (~250 MB) from its compressed copy — this happens once and takes a few seconds. It also checks GitHub for a newer catalogue and offers a one-click update if one exists.

That's it — OrthoGather opens in your browser. From here pick New Analysis, the Preselected Dataset, or External Upload.
Every time after this, you only need two lines: 
conda activate orthogather
python app.py
Prefer a guided installer?

From inside the OrthoGather folder, run the script for your system. It checks prerequisites, builds the same orthogather environment and verifies OrthoFinder.

./install_orthogather_mac.sh
./install_orthogather_wsl.sh
Other ways to install

Windows

OrthoFinder runs on Linux/macOS, so on Windows install WSL first, then follow the Linux / WSL steps inside it.

pip (advanced)

Already have Python 3.11? pip install -r requirements.txt covers the Python packages, but you must install OrthoFinder 2.5.5 separately (it is not on PyPI) — conda/bioconda is the supported route.

Troubleshooting
conda: command not found
Conda isn't installed (or your terminal hasn't loaded it). Install Miniforge, then close and reopen your terminal and try again.
Species list is empty / catalogue didn't load
The catalogue unpacks itself from the compressed copy on first launch, so this is rare. If it happens, delete the half-written raw file and restart — the app re-unpacks it from proteomes_list.json.gz: 
rm -f static/Proteomes_json/proteomes_list.json
python app.py
Still stuck? Open the catalogue menu on the species page and click Check for updates to download a fresh copy from GitHub.
"OrthoFinder not detected"
Make sure the environment is active — your prompt should show (orthogather). If not, run conda activate orthogather and launch again.
OrthoFinder runs slowly or uses too much CPU
OrthoGather auto-detects your cores. To leave headroom for other work, set the thread counts before launching: 
ORTHOGATHER_OF_THREADS=6 ORTHOGATHER_OF_ANALYSIS_THREADS=1 python app.py
